## ✨ Features

| Feature | Description |
|---------|-------------|
| 📷 **Scan Receipts** | Take a photo or upload from gallery |
| 🧠 **AI Extraction** | Google Document AI extracts merchant, total, date, tax, and line items |
| 📊 **Dashboard** | View totals, confidence scores, and recent receipts |
| 📋 **Receipts List** | Search, filter, and review all your receipts |
| 📈 **Reports** | See spending breakdowns and trends |
| 📤 **Export** | Download receipt data as CSV |
| 🔒 **Secure** | Your data is stored in the cloud, accessible from anywhere |

## 🛠️ Tech Stack

### Frontend (Mobile)
- **React Native** (Expo)
- **TypeScript**
- **React Navigation** (Bottom Tabs + Stack)
- **Expo Image Picker** (camera + gallery)
- **Reanimated** (smooth animations)

### Backend
- **Python** (FastAPI)
- **Google Document AI** (OCR + entity extraction)
- **SQLite** (local database)
- **Render** (hosting)

## 📱 How to Run Locally

How to Run Locally
Prerequisites

Node.js 18+

Expo CLI

iOS Simulator (Mac) or Android Emulator

Steps

bash
# Clone the repository
git clone https://github.com/brentobox88/ReadReceiptsMobile.git
cd ReadReceiptsMobile

# Install dependencies
npm install

# Start the development server
npx expo start
Scan the QR code with Expo Go on your phone, or press a for Android emulator / i for iOS simulator.
